# ファナック 計算資料

2026年9月22日作成。金額は百万円、株式数は百万株、EPS・株価は円。
実績表は会社開示、予測と評価の仮定はMarket Noteの独自推計。
全勘定を連動させた三表モデルではなく、売上・利益・FCFFのドライバーモデル。

## 1. 利益予測の全入力

純利益 = (営業利益 + 持分法を除く営業外純収益) x 70% + 持分法利益 - 非支配利益
EPS = 純利益 / 期中平均株数
営業利益 = 売上高 x 営業利益率（百万円へ四捨五入）
持分法利益は投資先課税後の利益持分を含むため、一律30%を再課税しない簡便法。

持分法以外の営業外純収益、非支配利益も独自仮定であり会社計画ではない。

## 2. DCF

FCFF = 営業利益 x 70% + 減価償却 - 設備投資 - 運転資本増分
残存期間: 2027年3月期は通期FCFFの50%、以降は通期分。
割引期間: 0.5、1.5、2.5、3.5、4.5年（期末発生）。
WACC 7.5%、永久成長率2.5%、終価期ROIC15%。
終価FCFF = 最終年NOPAT x (1+g) x (1-g/終価期ROIC)
終価現在価値 = 終価FCFF / (WACC-g) / (1+WACC)^4.5
企業価値 = 明示期間FCFF現在価値合計 + 終価現在価値

## 5. 実績指標の定義

ROIC簡便値 = 183,763 x 70% / 期首期末平均投下資本 = 11.4650%
2025年3月末投下資本 = 1,724,545 + 7,291 - 590,504 - 16,000
2026年3月末投下資本 = 1,864,871 + 7,611 - 718,071 - 35,800
投資有価証券192,214 / 223,287をそれぞれ追加控除した参考ROIC = 14.0704%
在庫日数 = ((306,439 + 292,186) / 2) / 529,365 x 365 = 206.38日
CFO/純利益 = 250,896 / 166,543 = 1.5065倍
営業CF - 有形固定資産支払 = 250,896 - 21,181 = 229,715
上記から在庫CF押上げのみ控除 = 229,715 - 27,869 = 201,846
長期表の現金創出目安はCFO - 設備投資額であり、この支払ベース指標とは異なる。
